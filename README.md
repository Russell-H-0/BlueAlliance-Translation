# 雷霆专区 BlueAlliance 翻译组 · 稿件仓库

把外网关于雷霆的好文章译成中文，发在虎扑雷霆专区。这里是稿件、原文和组内文档。

**这个文件夹可以直接打包发给组内成员。** 根目录下的东西都是给成员看的；
`_ops/` 是选题与流程的维护区（工具脚本、候选打分表、台账、审核中转），打包时**不要带**。

- 想知道怎么干活 → [WORKFLOW.md](WORKFLOW.md)（工作手册）
- 刚接校对 → [REVIEW-GUIDE.md](REVIEW-GUIDE.md)（一页说明，5 分钟看完）
- 查某个文件在哪 → 就是本页

---

## 目录

| 路径 | 放什么 | 说明 |
|---|---|---|
| `drafts/` | 待审与成品译稿，一篇一个 `.md` + 同名 `.docx` | 成员主要看这里 |
| `sources/` | 原文全文与元信息（标题、作者、媒体、日期、链接） | 校对核原文用 |
| `published/` | 已发布稿件的专区链接与回填数据 | 回溯用 |
| `glossary.csv` | 译名与术语统一表（球员、规则、数据、战术） | 翻译前必看，随时可补 |
| `WORKFLOW.md` | 工作手册：选题、翻译规范、校对、署名 | 全体 |
| `REVIEW-GUIDE.md` | 校对岗的一页说明 | 校对 |
| `_ops/` | **维护区，不对外**：`AGENTS.md`（自动流程说明）、`PLAN.md`（方案与待办）、`scripts/`（工具）、`candidates/`（每日候选与热度数据）、`log.csv`（抓取台账）、`review_log.csv`（校对留档）、`review/`（审核包收发与改动清单）、`templates/`（群通知文案） | 维护者 |

## 一份稿子要经过什么

```
选题扫描 → 打分与热度核对 → 全译 → 自校 → 出稿（drafts/）
        → 审核包发出 → 成员校对 → 返稿比对 → 终稿 → 发布（published/）
```

成员参与的是中间两段：拿到审核包校对、把改动回传。选题和打分由维护者完成，
依据（候选分数、热度数据）会在每日推送里公布。

## 三条硬规矩

1. 数字、引语、作者观点必须能在原文找到，不添加原文没有的判断
2. 付费墙抓不到全文就只做摘要并标注，不硬凑
3. 发布前必须有真人校对，文末同时署译者和校对
