# PR 模板

## 标题

```
审回：<中文标题>（@<你的ID>）
```

例：`审回：华莱士续约：雷霆5年1.39亿美元锁定年轻后卫（@dpyeah）`

## 正文

```markdown
## 审的是哪篇
- 文件：`drafts/<日期>_<篇名>_审核包.docx`
- 原文：<原文链接>

## 我改了什么
- 改了 <N> 段
- 其中：数字 <a> 处、引语 <b> 处、人名/术语 <c> 处、语感 <d> 处

## 拿不准、需要译者裁决
1. 第 <X> 段：「<原句>」→ 我改成「<改后>」，理由是 <一句话>
2. …（最多 3 条，多了说明这篇问题大，直接群里聊）

## 没动的地方
- 英文段未动
- 未做整段删除
```

## 提交信息（commit message）

```
审回：<中文标题>（@<你的ID>）
改了 <N> 段，其中数字 <a> 处、引语 <b> 处
```

## 规矩

- 一个 PR 只放一篇稿子的返稿，不要混装
- 不要自己合并 PR；合并由维护者做
- 不要顺手改别的文件（包括别的篇目、glossary，除非是补术语且说明理由）
